# Real-Estate-Price-intelligence-report-and-model
Developed a data-driven real estate price analysis and prediction project using Python, Pandas, and Power BI on 1M+ Connecticut property records (2001–2021). Built an interactive Power BI dashboard for KPIs, regional segmentation, and property types, and trained a Random Forest model (RMSE: 0.68) to forecast 3BHK prices for 2030.
